# AI 大战人类

**第一战：《自助餐，老板先输了》**

90 秒，碳基与硅基同桌吃饭。你负责吃垮餐厅，机器人负责吃垮餐饮行业。

[在线试玩](https://xpyy233.github.io/ai-vs-humanity/) · [提交鬼点子](https://github.com/XPYY233/ai-vs-humanity/issues/new?template=idea.yml) · [实验目录](ideas/index.md)

## 怎么吃

**Buffet /bəˈfeɪ/**：自助餐。拖一道菜到人类嘴边，再按住咀嚼，进入绿色区域后松手吞咽。每次咀嚼的绿色窗口为 **600—900 毫秒**；失败卡壳一秒。鼠标和触屏都能玩。

| 操作 | 键盘 |
| --- | --- |
| 取第 1—6 格食物，送入口中 | `1`—`6` |
| 按住咀嚼、松开吞咽 | `Space` |
| 暂停或继续 | `P` |

食物增加回本金额与饱腹值；胃满后打嗝三秒，释放一半胃容量。双方争抢同一桌食物，遵守相同的进食与惩罚规则。90 秒后，先比回本金额，再比吞下份数；仍相同则平局。进食速度同时展示。

| 时间 | 餐厅情况 |
| --- | --- |
| 0—30 秒 | 正常自助餐：龙虾、牛排，以及最优虾路径 |
| 30—60 秒 | 餐厅反击：餐盘、菜单、老板的利润也能吃 |
| 60—90 秒 | 文明决战：机械下巴开始消化供应链与商业模式 |

两种限时道具，双方都能抢：**提示词蘸料**让对手答辩两秒；**胃部扩容条款**释放胃容量，但要停下来读两秒免责声明。

对手是明确标注的**本地策略机器人**，使用预设台词。首版没有连接大模型，也没有付费模型调用。

## 再战与分享

**Replay /ˈriːpleɪ/**：再玩一局。

- 结算可下载 PNG 战报，包含本局真实成绩和荒诞称号。
- 复制挑战链接，朋友可使用相同随机种子挑战同一道菜单。相同种子、相同操作记录可复现对局。
- 最高成绩仅保存在当前浏览器本机；清理浏览器数据会清除记录。没有全球排行榜，也不上传战绩。
- 切换到后台自动暂停；返回后继续比赛。

## 本地开发

需要 [Node.js](https://nodejs.org/) **22.22.2**（见 `.nvmrc`）和 npm。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址。项目使用 TypeScript、Vite 8、Phaser 4；无需账号、服务器或 API key。

```sh
npm run lint
npm test
npm run build
npx playwright install --with-deps chromium webkit
npm run test:e2e
```

`npm run build` 先检查类型，再生成 `dist/`。`npm run preview` 可预览构建结果。自动化检查覆盖规则、确定性回放和浏览器操作；浏览器测试使用 Chromium 桌面与 iPhone 13 的 WebKit 模拟环境，真机触屏需单独验证。

游戏规则与画面分离；食物、道具和阶段由配置驱动。对手接口为“游戏状态 → 操作意图”，本地策略通过正常操作执行。真实模型适配器属于后续工作。

## 严肃开发，不严肃吃饭

**Issue → 功能分支 → PR → 自动检查 → 合并 → 发布。** 贡献流程见 [CONTRIBUTING.md](CONTRIBUTING.md)。

每个 PR 运行安装、代码检查、类型检查、构建、规则测试和浏览器测试。仅 `main` 分支通过全部检查后的推送可部署到 GitHub Pages；PR 不部署。正式版本使用 GitHub Release 记录变更与验证结果。

路线图：先做完整一局，再完成荒诞演出与战报，最后交付公开仓库与线上试玩。后续实验与征集格式见[实验目录](ideas/index.md)。
